## <a name="english"></a>🇬🇧 English
A lightweight Command-Line Interface (CLI) utility tool designed for Android Termux. It includes a File Manager, System Info, Network Info, and Battery Status. 

**Compatibility:** Compatible with Android 6 (Marshmallow) and above.

### ✨ Features
- **File Manager:** `ls` (list files) and `move` (move files/folders).
- **System Info:** Check RAM usage and Uptime.
- **Network:** Display local IP address.
- **Battery:** Check battery percentage.

### 📥 How to Install & Run
1. Clone this repository: `git clone https://github.com/kornengelforwork-alt/termux-linux.git`
2. Navigate to the folder: `cd termux-linux`
3. Run the tool: `python tool.py`
