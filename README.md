## <a name="english"></a>🇬🇧 English

A collection of lightweight Command-Line Interface (CLI) tools and OS simulators designed for Android Termux. 

**Note for Utility Tools:** 
**For normal use, use version v2, but for multitasking, we recommend using version v1.**

### 🛠️ Utility Tools
- **`toolv2.py` (Version 2):** A visual system information tool (Neofetch-style) that displays OS details, RAM, IP, and battery. Perfect for a quick system check.
- **`tool.py` (Version 1):** An advanced interactive utility featuring a File Manager (`ls`, `move`), live System Monitor, and multilingual support. Recommended for multitasking and file management.

### 💻 Other Projects
- **OS Simulators:** `linux.py`, `win3.py`, `kornengelOS.py`
- **Games:** `mazegame.py`, `dungeon_rpg.py`, `testtype.py`
- **Networking:** `chatserver.py`, `chatuser.py`

### 📥 How to Install & Run
1. Clone this repository: `git clone https://github.com/kornengelforwork-alt/termux-linux.git`
2. Navigate to the folder: `cd termux-linux`
3. Run any tool (e.g., `python toolv2.py`)

## <a name="thai"></a>🇹🇭 ภาษาไทย (For Thai Users)

รวมเครื่องมือ Utility แบบ CLI และระบบจำลอง OS สำหรับ Android Termux

**หมายเหตุสำหรับเครื่องมือ Utility:**
**ถ้าใช้ธรรมดาธรรมดาให้ใช้ v2 แต่ถ้าใช้งานขั้นสูงหรือใช้งานหลายอย่างให้ใช้ v1**

### 🛠️ เครื่องมือ Utility
- **`toolv2.py` (เวอร์ชัน 2):** โปรแกรมแสดงข้อมูลระบบแบบเห็นภาพ (สไตล์ Neofetch) โชว์ข้อมูล OS, RAM, IP และแบตเตอรี่ เหมาะสำหรับการเช็กสเปกเครื่องแบบเร็วๆ
- **`tool.py` (เวอร์ชัน 1):** เครื่องมือแบบโต้ตอบขั้นสูง มีระบบจัดการไฟล์ (`ls`, `move`), ระบบตรวจสอบสถานะแบบเรียลไทม์ และรองรับ 2 ภาษา แนะนำสำหรับการใช้งานหลายอย่างพร้อมกัน

### 💻 โปรเจกต์อื่นๆ
- **ระบบจำลอง OS:** `linux.py`, `win3.py`, `kornengelOS.py`
- **เกม:** `mazegame.py`, `dungeon_rpg.py`, `testtype.py`
- **ระบบเครือข่าย:** `chatserver.py`, `chatuser.py`

### 📥 วิธีติดตั้งและใช้งาน

2. เข้าโฟลเดอร์: `cd termux-linux`
3. รันโปรแกรม (เช่น `python toolv2.py`)
